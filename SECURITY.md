# Security Policy

## Supported version

Security fixes are applied to the latest revision of the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately to the repository owner at `andrii.iudin@gmail.com` with:

- the affected component
- steps to reproduce
- the potential impact
- any suggested mitigation

Do not include real personal, justice, customer, or employer data in a report.

## Scope and limitations

JusticeFlow is a portfolio demonstration that uses synthetic data. It is not approved for real justice data or production operational use.

The repository includes automated dependency audits, runtime image vulnerability scans, signed-token validation, role-based authorization, and non-root runtime images. These controls reduce risk but do not replace threat modelling, penetration testing, information-governance approval, private networking, secret rotation, or operational security review.
