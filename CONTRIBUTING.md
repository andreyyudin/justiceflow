# Contributing to JusticeFlow

JusticeFlow is a portfolio demonstration built entirely with synthetic data. Contributions should preserve its responsible-AI boundaries, production-shaped authentication path, accessibility requirements, and local-first workflow.

## Before submitting a change

- Do not add real justice, personal, customer, or employer data.
- Do not introduce an authentication bypass.
- Keep model recommendations advisory and subject to explicit human review.
- Preserve deterministic safeguards and auditable human decisions.
- Add or update tests for changed behaviour.
- Run the relevant local quality checks documented in `README.md`.
- Do not run Terraform plan or apply against an employer or customer subscription.

## Pull requests

Keep changes focused and explain:

- the problem being solved
- the approach taken
- security, privacy, accessibility, and responsible-AI implications
- tests and validation performed

All continuous-integration checks must pass before merge.
